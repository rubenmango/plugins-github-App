01

User flows

End-to-end paths in the running prototype.

  1. Open from PR. Bot comment → Open full review → login gate (repo / PR #356 / file) → Sign in (mimic) → unified editor.
  2. Review on canvas. Green added nodes; pill #356 +6 -0; Design/Code via pill; Discard / Approve top-center; AI sparkle bottom-center.
  3. Approve & push. Push to repo → Pushing… → Pushed to (purple open-PR chip) → exit; pill/tag become merged purple + merge icon.
  4. Soft-dismiss. Sparkle hides review chrome but keeps PR context; click pill to restart unfinished review. Hard Discard fully exits.
  5. Dashboard. Personal files exclude linked diagrams. GitHub → Connected repos lists them; Connect GitHub repo CTA is logo-branded.
